# Agent transcripts

This project was built with an AI coding agent (Claude Code) directing the implementation. This
folder documents how the agent was directed, verified, and corrected — including **failed attempts
and their fixes** — per the assignment's transcript requirement.

- [`development-log.md`](development-log.md) — chronological build narrative: decisions, dead-ends,
  errors hit, and how each was resolved.

No secrets or sensitive data are included (the project keeps all secrets in a git-ignored `.env`).

> To attach the raw session transcript, export your coding-agent session and drop it in this folder
> (scrub any keys first).
